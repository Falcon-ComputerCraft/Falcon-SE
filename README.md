# Falcon SE
Falcon Special Environment is a heavily cut down version of Falcon OE. Unlike the normal falcon, there is no taskbar. Everything is lightweight and independent so that Falcon SE can run when the normal falcon OE is non functional. Falcon SE is used  as a recovery environment and a preinstallation environment.

## Using Falcon SE
Falcon SE needs a few arguments to start properly. Here is a table based on what you need.

Text wrapped in brackets [like this] needs to be replaced with what you need. For example, [InstallURL] becomes example.com/filename.lua.

|Argument #|Recovery |Install single file to disk
|--|--|--|
|Arg 1 | recover | installToDriveSF   |
|Arg 2 | N/A | [InstallURL]  |
|Arg 3 | N/A | [FileNameOnceOnDrive]  |
